On GitHub Copilot, load modemax skills by their bare names through the `skill` tool (`modemax`, `tdd`, `architect`, not `modemax:modemax`); the plugin's agents keep the prefix (`modemax:modemax-agent`, `modemax:comment-sicko`). Copilot lists only part of a large plugin's skills in its prompt; every modemax skill a workflow names still loads by that name. `.github/copilot-instructions.md` and `~/.copilot/copilot-instructions.md` count as user instructions. Resolve every Claude tool, model, path, and built-in skill a modemax skill names through `references/copilot-tools.md` in the `modemax` skill directory. modemax ships no default Copilot models. A skill that dispatches on role models takes them from the user's saved modemax model choices. The plugin hook reads them from the Copilot model sheet, `${COPILOT_HOME:-~/.copilot}/modemax-models.md`, checks them, and adds them to the end of this block. Do not `view` the sheet. It sits outside the workspace, so reading it asks for path access. After `setup-modemax` writes the sheet in this session, use the values it just wrote.

Skills that dispatch on role models: `architect`, `arena`, `how`, `interrogate`, `modemax`, `reflect`, `swarm`, `why`.
